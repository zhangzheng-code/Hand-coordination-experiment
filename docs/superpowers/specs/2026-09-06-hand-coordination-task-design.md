# 手部协调能力任务网页设计规格

## 目标与范围

构建一个使用 React、TypeScript、Vite 和原生 CSS 的单页小实验。核心是实现顺滑、连续、可跨多次按压累计的旋钮拖动交互，并保持页面简洁、正式、克制。

本项目不包含后端、数据库、路由、状态管理库、UI 框架、Canvas、Three.js 或复杂数据分析。

## 页面结构

应用包含三个互斥状态，由 `App` 内部状态切换，不引入路由。

### 介绍页

- 标题：手部协调能力任务
- 正文：
  - 接下来，您将完成一项简单的手眼协调任务。
  - 请按照屏幕提示完成操作，尽可能准确完成所有步骤。
- 操作按钮：开始任务

### 任务页

- 标题：手部协调能力任务
- 提示：请使用鼠标拖动中央旋钮，按照箭头方向旋转。
- 显示当前进度，例如 `3 / 10`
- 显示“顺时针旋转约 30°”作为本轮目标
- 中央实验卡片在桌面端约 600px × 420px，在较窄视口下自适应缩小
- 卡片内包含旋钮、八向细线标记和固定高度的轻量状态反馈区域

### 完成页

- 标题：任务完成
- 正文：感谢您的参与。
- 操作按钮：重新开始
- 重新开始会清空进度、累计角度和反馈状态，返回第一次任务

## 组件与职责

- `src/App.tsx`：管理介绍、任务、完成三种页面状态；保存完成次数；处理单次成功和重新开始。
- `src/components/Knob.tsx`：负责指针事件、角度计算、连续累计、松手判断和旋钮视觉。
- `src/rotation.ts`：提供可独立测试的角度差归一化与任务角度判断函数。
- `src/styles.css`：集中维护页面、卡片、旋钮、方向标记、反馈和响应式样式。

## 配置

以下配置集中定义，不在组件中散落硬编码：

```ts
export const TOTAL_TRIALS = 10;
export const TARGET_ANGLE = 30;
export const ANGLE_TOLERANCE = 5;
```

成功反馈持续约 350ms，随后进入下一次任务。

## 旋转交互

1. 按下旋钮时获取旋钮圆心，并通过 `atan2(y - centerY, x - centerX)` 计算当前指针角度。
2. 使用 Pointer Events，使鼠标按下后即使移出旋钮区域仍能持续拖动。
3. 每次指针移动只计算“当前原始角度 - 上一次原始角度”。
4. 将角度差归一化到 `-180°～180°`，避免跨越 `180° / -180°` 时发生跳变。
5. 将归一化后的角度差累加到旋钮总角度和当前任务角度。
6. 顺时针为正方向。松手后旋钮保持当前位置，不复位。
7. 如果本次累计不足，下一次按下继续累计剩余角度，不重新开始计算。
8. 如果累计超过上限，任务保持未完成；用户可以逆时针退回容差区间，再松手完成。
9. 仅在松开指针时判断：当前任务累计角度在 25°～35° 时成功，否则显示轻提示。

## 成功与状态流

- 成功时旋钮外围边框短暂加深，并显示“完成”。
- 成功反馈期间锁定旋钮，避免重复触发。
- 约 350ms 后：
  - 如果尚未完成第 10 次，将当前任务累计角度清零，但保留旋钮总角度，并进入下一次。
  - 如果已完成第 10 次，进入完成页。
- 失败时显示“请继续按照提示旋转约 30°”，旋钮角度及本次任务累计值均保留。

## 视觉设计

- 页面背景使用白色或接近白色的浅灰色，最大内容宽度约 900px。
- 字体使用系统无衬线字体，主要文字为 `#111 / #222`，辅助文字为 `#666`。
- 实验卡片使用约 24px 圆角、`#f1f1ef` 一类浅灰背景和淡边框，不使用明显阴影。
- 旋钮直径约 156px，由浅灰外层、白色内层、深色中心点和短指针组成。
- 八向提示使用 CSS 细线与箭头端点，不使用大型字符箭头。
- 按钮为深色实底，只有轻微 hover 位移或颜色变化。
- 不使用复杂渐变、鲜艳色、大动画、音效、积分或庆祝效果。

## 无障碍与响应式

- 交互元素使用原生按钮语义。
- 旋钮提供清晰的可访问名称和拖动状态描述。
- 拖动时禁用触摸浏览器的默认平移行为。
- 页面在普通笔记本尺寸下不溢出；窄屏时实验卡片宽度降为容器宽度，旋钮和主要空间关系保持可用。

## 测试与验收

自动化测试覆盖：

- 普通相邻角度差计算。
- 从 `179°` 到 `-179°` 及反向跨边界时不会产生约 358° 的跳变。
- 顺时针 25°、30°、35° 判定成功，边界外判定失败。
- 多段拖动角度可以累计完成一轮。
- 成功后保留旋钮总角度，仅清零下一轮的任务累计角度。

手动浏览器验收覆盖：

- 介绍页、任务页和完成页切换正确。
- 旋钮拖动顺滑，离开旋钮区域仍可继续拖动。
- 跨过 ±180° 时无视觉跳变。
- 松手后再次拖动可继续累计未完成角度。
- 单次完成后旋钮不复位。
- 连续完成 10 次后进入完成页，重新开始可正确重置。
- 窄窗口下页面不发生横向溢出。
- `npm run build` 无报错。
