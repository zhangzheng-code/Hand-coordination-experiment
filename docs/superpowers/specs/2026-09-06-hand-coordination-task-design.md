# 手部协调能力任务网页设计规格

## 目标与范围

构建一个使用 React、TypeScript、Vite 和原生 CSS 的单页小实验。核心是让用户在 5 分钟内重复点击 8 个圆盘，每次点击使对应指针固定顺时针旋转 90°，并保持页面简洁、正式、低认知负荷。

本项目不包含后端、数据库、路由、状态管理库、UI 框架、Canvas、Three.js 或复杂数据分析。

## 页面结构

应用包含三个互斥状态，由 `App` 内部状态切换，不引入路由。

### 介绍页

- 标题：手部协调能力任务
- 正文：
  - 接下来，您将完成一项简单的手眼协调任务。
  - 请按照屏幕提示重复点击圆盘，任务将持续约 5 分钟。
- 操作按钮：开始任务

### 任务页

- 标题：手部协调能力任务
- 提示：请点击下方任意圆盘，每次点击将顺时针旋转 90°。
- 不显示点击次数、轮次进度、进度条或倒计时数字
- 实验卡片在桌面端使用 4 列 × 2 行，共 8 个圆盘
- 窄屏自动改为 2 列 × 4 行，全部圆盘保持可点击
- 进入任务页时启动固定 5 分钟的隐藏计时

### 完成页

- 标题：本次实验已结束
- 正文：感谢您的参与。
- 不显示按钮，不自动重新开始

## 组件与职责

- `src/App.tsx`：管理介绍、任务和结束三种页面状态；进入任务时启动 5 分钟计时，到时自动切换结束页。
- `src/components/Knob.tsx`：表示一个独立圆盘，负责点击或键盘激活、固定 90° 累加和轻微视觉反馈。
- `src/components/KnobGrid.tsx`：渲染 8 个圆盘并提供稳定的 4×2 / 2×4 布局。
- `src/styles.css`：集中维护页面、实验卡片、圆盘网格和响应式样式。

## 配置

以下配置集中定义，不在组件中散落硬编码：

```ts
export const KNOB_COUNT = 8;
export const ROTATION_STEP = 90;
export const TASK_DURATION_MS = 5 * 60 * 1000;
```

## 旋转交互

1. 8 个圆盘始终都可点击，不规定顺序，也不高亮指定目标。
2. 每个圆盘独立保存自己的累计角度。
3. 每次有效点击将对应圆盘角度精确增加 `ROTATION_STEP`，默认由 0° 依次变为 90°、180°、270°、360°。
4. 点击没有轮次等待，用户可以连续操作不同圆盘。
5. 圆盘使用原生按钮语义，同时支持鼠标点击、Enter 和空格键激活。

## 计时与状态流

- 用户点击“开始任务”时进入任务页并启动 `TASK_DURATION_MS` 计时器。
- 任务进行时不显示剩余时间，只显示“任务将持续约 5 分钟”的静态说明。
- 5 分钟到达后自动停止交互并切换至无按钮的结束页。
- 组件卸载时清理计时器，避免重复回调。

## 视觉设计

- 页面背景使用白色或接近白色的浅灰色，最大内容宽度约 900px。
- 字体使用系统无衬线字体，主要文字为 `#111 / #222`，辅助文字为 `#666`。
- 实验卡片使用约 24px 圆角、`#f1f1ef` 一类浅灰背景和淡边框，不使用明显阴影。
- 8 个圆盘使用统一尺寸，由浅灰外层、白色内层、深色中心点和短指针组成。
- 圆盘之间留出充足间距，页面不显示方向箭头、成功文字或游戏化反馈。
- 按钮为深色实底，只有轻微 hover 位移或颜色变化。
- 不使用复杂渐变、鲜艳色、大动画、音效、积分或庆祝效果。

## 无障碍与响应式

- 交互元素使用原生按钮语义。
- 每个圆盘提供唯一按钮名称，例如“旋转圆盘 1”，并暴露当前累计角度。
- 页面在普通笔记本尺寸下不溢出；窄屏时实验卡片宽度降为容器宽度，旋钮和主要空间关系保持可用。

## 测试与验收

自动化测试覆盖：

- 页面渲染 8 个独立圆盘按钮。
- 点击其中一个圆盘只使该圆盘增加 90°，其余圆盘角度不变。
- 同一圆盘连续点击可累计至 180°、270°及更高角度。
- 任务页不出现次数、进度条、“完成”或“重新开始”。
- 5 分钟计时到达后进入无按钮结束页。

手动浏览器验收覆盖：

- 介绍页、任务页和完成页切换正确。
- 页面包含 4×2 共 8 个圆盘，窄屏为 2×4。
- 点击任意圆盘后，仅对应指针固定顺时针转动 90°。
- 用户可持续重复点击，不显示次数和动态计时。
- 等待 5 分钟后自动进入“本次实验已结束”页面。
- 窄窗口下页面不发生横向溢出。
- `npm run build` 无报错。
